# Phase 3 gate: an honest FAIL

*2026-08-05 · ai-portfolio-sentinel · learning lane. Status: in
development toward production-ready. No production claim is made here.*

The caged checker agent is built, tested, and it failed its own gate.
That's the whole news, and it's worth saying plainly before anything
else: pooled precision came in at 0.8393 against a 0.90 floor, pooled
recall at 0.7833 against 0.85, and the two classes this phase adds —
`stale-STATE-marker` and `missing-synthetic-label` — landed at 2/10
and 5/10 recall against an 0.80 per-class floor. Phase 3 stays open.
No fixture, threshold, prompt, or model choice changed after seeing
that result, and none will in this session — that's the whole point of
freezing a gate before running it.

What did land, and landed clean: a real cage around Haiku — no
built-in tools, exactly one custom tool, a bounded turn count, an
independent tool-call breaker, and a run-scoped EUR budget instead of
a per-call one. The model never emits a finding directly; it proposes
a reason code plus a verbatim line and excerpt, and host code checks
every citation against the actual document before anything becomes a
real finding — free-form model text never touches the fingerprint. A
new ledger table audits every call: reserved before the SDK is
invoked, finalized after, a crash-orphaned call charged at its
reservation rather than zero. 535 tests pass, 3 skip (Phase 4 only,
pinned by a self-checking test), and a static scan still proves the
model SDK is imported nowhere but the one new package.

The gate run itself surfaced something the design hadn't accounted
for. The run-scoped budget is shared across the primary scoring pass
and the doubled-fixture idempotency pass — one EUR 0.50 ceiling for
both, not one each — and the first pass spent every cent of it. The
second pass made zero real model calls. Its findings correctly stayed
untouched rather than falsely resolving, which is real evidence the
exhaustion path is safe. It is not evidence that a second real pass
would agree with the first, because there wasn't one. That distinction
matters enough to spell out in the results file rather than let a
green invariant imply more than it proved.

Four deterministic classes held at 10/10 recall, same as Phase 2,
completely unaffected by any of this — the shortfall is isolated to
the two classes the agent is actually responsible for. That's useful:
it says the cage held and the miss is a judgment-quality question, not
a plumbing one. What's next isn't a rerun. A dispatch that reruns a
failed gate after tweaking a prompt is gate-shopping, and the binding
rule here is explicit that remediation needs its own approved decision
before any of that happens.

Real data this time, not synthetic: real Haiku 4.5 calls under my own
subscription, scored against the frozen synthetic fixture bed
(unchanged since `4d46c1d4fc3c4f485a83f44fa54afa6b04b1f541`). The
scheduled daily run stays exactly as it was — stub mode, unedited, no
model calls, nothing about today changes what it does tomorrow morning.

Q-77 stays open. Phase 3 stays open.
